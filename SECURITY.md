# Security policy

Report vulnerabilities through
[GitHub private vulnerability reporting on the main repository](https://github.com/0xcuy/adexto/security/advisories/new).
The MCP server at `https://adexto.xyz/api/mcp`, including `pay_and_buy`, and the agent kit in this repository are
in scope. The full policy is [SECURITY.md in 0xcuy/adexto](https://github.com/0xcuy/adexto/blob/main/SECURITY.md).

Please do not open a public issue for a vulnerability.
